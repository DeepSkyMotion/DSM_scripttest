# DSM_scripttest

Development and testing update repository for DeepSkyMotion PixInsight scripts.

**Not for general use.** Everything here is work in progress and may change or disappear at any time.
Finished scripts are published in [DeepSkyMotion_scripts](https://github.com/DeepSkyMotion/DeepSkyMotion_scripts).

Scripts from this repository appear in PixInsight under **Script > DSM Test**.
